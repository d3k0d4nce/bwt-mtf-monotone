## Описание алгоритма

### 1. Преобразование Барроуза-Уиллера (BWT)

BWT переставляет символы входной строки так, чтобы одинаковые символы шли подряд. Алгоритм:

1. Составляется таблица всех циклических сдвигов входной строки.
2. Производится лексикографическая сортировка строк таблицы.
3. Выход — последний столбец таблицы и номер строки, совпадающей с исходной.

Обратное преобразование использует `firstPos` и `next` (оптимизированный наивный алгоритм), что даёт сложность `O(n)` после предподсчёта.

### 2. «Стопка книг» (MTF, Move-To-Front)

MTF заменяет каждый символ на его позицию в динамическом списке из 256 символов. После BWT одинаковые символы идут подряд, поэтому их MTF-индексы становятся маленькими числами (0, 1, 2, …). Найденный символ перемещается на вершину стопки. Декодер выполняет то же самое преобразование, что обеспечивает синхронность.

### 3. Монотонный код

Монотонный код кодирует целые числа переменной длиной:

```
mon(0) = "0"
mon(n) = unar(⌊log₂ n⌋ + 1) | bin(n − 2^⌊log₂ n⌋),  n ≥ 1
```

где `unar(k)` — это `k` единиц, затем ноль, а `bin(x, k)` — `x` в двоичном виде ровно на `k` битах. Код является префиксным, поэтому декодер восстанавливает числа без дополнительной информации о длинах.

**Пример:** `mon(21) = 11110 0101`.

### Целочисленная реализация

Все преобразования выполняются над байтами, поэтому `MAX_RANGE` и другие 16-битные константы не используются — алгоритм работает напрямую с `int` и побитовыми операциями.
