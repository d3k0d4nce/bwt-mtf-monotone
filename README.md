## Описание алгоритма

### Арифметическое кодирование

Арифметическое кодирование кодирует всю последовательность символов в одно дробное число из интервала `[0, 1)`. В отличие от кода Хаффмана, оно может использовать дробное число битов на символ, что обеспечивает более эффективное сжатие.

### Адаптивная модель (Вариант D)

- Все 257 символов (0-255 + EOF) инициализируются с частотой 1
- После обработки каждого символа его частота увеличивается на 1
- При превышении суммы частот 16384 выполняется масштабирование (деление на 2)

### Целочисленная реализация

Для избежания проблем с плавающей точкой используются 16-битные целочисленные регистры:

```java
private static final long MAX_RANGE = 0xFFFFL;     // 65535
private static final long HALF = 0x8000L;          // 32768
private static final long QUARTER = 0x4000L;       // 16384
private static final long THREE_QUARTER = 0xC000L; // 49152
```

## Формат сжатого файла

```
[4 байта]  MAGIC = 0x41434431 ("ACD1")
[8 байт]   исходный размер файла
[остальное] арифметически закодированный битовый поток
```
